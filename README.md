# 浏览工作台 · Tab Workbench

独立开发的 Chrome Manifest V3 扩展，连接 [趁手](https://tools.hzcmzhfw.cn/) 与 [轻办](https://qingban.hzcmzhfw.cn/)。首版以工具发现与网站回访为核心。

## 本地安装

1. 打开 `chrome://extensions`，启用右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 `extension` 目录。
3. 固定插件图标。点击图标搜索工具，点击「标签管理」打开完整工作台。
4. 在普通网页点击插件图标，选择「截取当前网页」。仅截取可见区域。

也可以解压 `dist/tab-workbench-0.1.0.zip` 后加载解压目录。ZIP 不是 Chrome 商店已签名安装包。

## 已实现

- 两站 342 个工具入口（2026-10-08 页面抓取并按网址去重），支持搜索、站点筛选和本地收藏。
- 全窗口网页标签读取、域名分组、标题/网址搜索、跨窗口切换、关闭指定标签。
- 精确网址重复清理预览，优先保留固定标签，再保留活动标签；所有固定副本均受保护。
- 本次关闭的标签网址可以撤销重开（不恢复表单、页面状态或原窗口）。
- 当前窗口命名会话保存，按顺序恢复至当前窗口，保留固定状态并跳过已打开网址。
- 文字/图片右键入口，交接页复制内容后打开对应网站。
- 可见区域截图，预览、下载并打开轻办截图标注页。
- `Ctrl+Shift+K` / `Command+Shift+K` 打开管理页（快捷键可能与其他扩展冲突）。

## 首版边界

- 尚未发布 Chrome 商店，尚未创建 GitHub 远程仓库。
- 网站暂未提供通用输入接收协议；文字需要复制粘贴，截图需要下载后选择文件。网页图片仅提供地址，不能绕过跨域或登录限制自动抓取。
- 不替换新标签页；无云同步、自动休眠、完整窗口/Chrome 标签组恢复、稍后再看或导入导出。
- 右键文本处理目前打开轻办目录，用户选择具体工具；JSON 和截图可直达具体工具页。
- 没有访问统计。工具目录在发版时更新，不从网站加载远程脚本。
- 截图需要在目标网页的插件弹窗中发起；管理页按钮提供操作提示。

## 权限与数据

`tabs` 用于标签查询/操作；`storage` 保存收藏与会话；`activeTab` 用于用户点击插件后的截图；`contextMenus` 用于右键入口。未申请全站读取权限。

会话和收藏保存在扩展本地存储。交接内容暂存于 `storage.session`，交接页读取后移除。点击网站工具会正常访问对应网站，本插件不自动上传标签、文本或截图。

## 开发与验证

无需构建、无需生产依赖。

```sh
npm test
npm run check
python3 scripts/build_catalog.py
npm run package
```

`node scripts/verify_browser.mjs` 使用本机已有的 Playwright 和 Chromium，在隔离临时浏览器配置中加载真实扩展，验证搜索、收藏、重复预览、会话保存/恢复与弹窗，截图输出到 `output/playwright/`。其他电脑需要自行安装 Playwright 及 Chromium。
