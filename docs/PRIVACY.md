# 隐私与本地数据

浏览工作台不设用户账号，不接入访问统计或广告，不把标签列表、选中文字、截图或备份自动上传到服务器。

## 数据位置

- chrome.storage.local：收藏工具、最近使用的工具、稍后再看页面、工作会话和设置；Chrome 书签最近 20 次操作前的历史快照及用于识别外部修改的当前基线。
- chrome.storage.session：右键内容与截图交接。每份内容使用独立随机标识，交接页读取后移除；超过 30 分钟的记录会在下次创建交接时清理，浏览器退出后清空。
- 交接页面内存：当前正在展示的文本或截图，关闭后消失；刷新一次性交接页需重新发起。
- 本地下载：用户主动导出的截图和 JSON 备份。

没有后台抓取浏览记录，不申请所有网站的主机权限，不在页面注入脚本。用户点击插件图标后才获得当前页面截图权限。工作台不处理无痕页面。

## 访问网站

点击工具会导航到 tools.hzcmzhfw.cn 或 qingban.hzcmzhfw.cn。插件不自动附加待处理内容、不添加追踪参数、不发送遥测；网站正常加载网页、静态资源和模型，访问日志与处理行为请查看相应网站的隐私说明。

代码、目录和字体均随扩展打包；浏览器图标为包内图片，不从外部图标服务请求用户访问的域名。

## 清理与迁移

可删除已保存页面和会话、取消收藏、通过 JSON 备份迁移。卸载插件通常会删除该浏览器配置中的扩展数据，建议先备份。备份包含网址、标题和备注，用户应自行保管。

## 原生书签与历史

bookmarks 权限用于读写 Chrome 原生书签。插件操作直接更新浏览器；Chrome 同步如已启用，由 Chrome 按用户设置同步。快照只在扩展本地存储中保留，包含标题、网址、目录层级与顺序，不会发送给趁手、轻办或其他服务。unlimitedStorage 仅为完整历史提供本地存储空间，不增加网页访问权限。恢复操作先保存当前版本，再替换可编辑书签。
